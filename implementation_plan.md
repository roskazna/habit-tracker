# Трекер привычек - план и текущее состояние

## Цель

Создать личное веб-приложение на React для отслеживания привычек, задач и продуктивности с будущим размещением на хостинге, синхронизацией между компьютером и телефоном, БД и настоящими AI-рекомендациями.

## Принятые решения

- Frontend: React + TypeScript + Vite.
- Графики: Chart.js через react-chartjs-2.
- Иконки: lucide-react.
- Хранение локально: localStorage для автономной работы.
- Синхронизация: serverless endpoint `/api/state` + PostgreSQL.
- AI: serverless endpoint `/api/ai` + Gemini generateContent API.
- Доступ без аккаунта: общий личный ключ `APP_ACCESS_KEY`, который вводится в приложении на каждом устройстве.
- Дизайн: темный строгий дашборд, русский интерфейс.

## Реализованные функции

- Виджет текущего времени, даты и дня недели.
- Ежедневный мотивационный афоризм и кнопка смены цитаты.
- Персональный набор привычек для мужчины 45 лет с сидячим образом жизни:
  - вода и контроль гидратации;
  - измерение давления;
  - мягкая зарядка;
  - перерывы от сидения;
  - гимнастика для глаз;
  - прогулки;
  - отжимания;
  - приседания;
  - контроль соли;
  - вечернее восстановление.
- Добавление, редактирование, удаление, включение/выключение и изменение порядка привычек.
- Добавлены привычки: чистка зубов утром, чистка зубов вечером, 1 учебное видео.
- Обновлены привычки: чтение книги 1 час, стакан воды каждый час, ортопедический мостик 15 минут и корсет для осанки 2 часа; дыхательная пауза удалена.
- Добавлен журнал артериального давления с графиком систолического и диастолического значений.
- Добавлен журнал ежедневных шагов с графиком.
- Задачи с категориями `Дом`, `Работа`, `Личное`.
- Приоритеты, дедлайны, повторы, заметки и фильтры задач.
- Автоматическое создание следующего экземпляра повторяющейся задачи при выполнении.
- Визуализация прогресса:
  - круговая диаграмма за сегодня;
  - столбчатый график за неделю;
  - линейный тренд за месяц.
- Локальные рекомендации как fallback.
- Настоящие AI-рекомендации через `/api/ai`, когда настроен `GEMINI_API_KEY`.
- Синхронизация состояния через `/api/state`, когда настроен `DATABASE_URL`.
- Экспорт JSON-копии данных.
